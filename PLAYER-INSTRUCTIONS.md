# The Vanishing File — Player Instructions

Difficulty: Easy | Category: DFIR / Windows Forensics

## Scenario
At fictional Northbridge Logistics, a finance document disappeared shortly after unusual activity. Correlate simulated file audit and endpoint process records to reconstruct the incident.

## Objective
Identify the deleted document, associated user, timestamp, process ID, and Windows deletion event ID.

## Evidence
- `artifacts/file_audit.csv`
- `artifacts/process_activity.csv`

All timestamps are UTC. This is a fictional training scenario; no virtual machine is required. Do not treat these CSV records as raw exported Windows EVTX evidence.
